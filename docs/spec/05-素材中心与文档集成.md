# 05 - EduMeet 素材中心与文档集成

> 版本：v1.0 ｜ 状态：待评审 ｜ 关联：02 数据模型 / 03 API / 04 生成编排

---

## 1. 目标与范围

用户可**自定义导入**文章素材、图片、视频与 URL，平台完成解析与自动打标后进入素材库；素材可被三种场景集成：插入编辑器文档、作为生成上下文、作为引用卡片。本期覆盖导入、解析、打标、列表管理与文档插入全链路。

## 2. 素材类型与处理流水线

| 类型 | 支持格式 | 大小限制 | 处理流水线 |
|---|---|---|---|
| image | jpg/png/webp/gif | 20MB | 预签名直传 → 缩略图生成 → 素材理解 Agent 打标 |
| video | mp4/mov/webm | 500MB | 直传 → 异步转码（720p）→ 封面帧截取 → 打标 |
| doc | docx/pdf/txt/md | 50MB | 直传 → 正文抽取（python-docx / PyMuPDF）→ 切片摘要 → 打标 |
| url | http(s) 链接 | — | 服务端抓取 → 正文抽取（readability）→ 存 extracted_text → 打标 |

### 2.1 上传流程（预签名直传）

```
前端 → POST /materials/presign（校验类型/大小）
     → 返回 {upload_url, file_key} → 前端直传 OSS
     → POST /materials 登记 → 入库 status=0(处理中)
     → Celery 队列 ingest：解析/转码/打标 → status=1(就绪)
```

### 2.2 自动打标（素材理解 Agent）

- 输出 tags：`{"theme": "幼升小政策", "grade": "primary", "summary": "一句话摘要", "keywords": []}`
- 图片：多模态模型识图描述；视频：封面帧 + 转写摘要（一期可仅封面帧）；文档：首尾切片摘要。
- 打标失败不阻塞：status=1 但 tags 为空，允许用户手工补标。

## 3. 素材与文档集成（核心需求④）

| 集成方式 | 交互 | 数据落点 |
|---|---|---|
| 编辑器插入 | 编辑器右侧素材面板拖拽 / 点击插入；图片入 image 块、视频入 video 块、文档入引用卡片 | `article_blocks.material_id` + `article_assets(usage=embedded)` |
| @ 唤起选择器 | 编辑器输入 `@` 唤起素材搜索浮层，支持标题/标签检索 | 同上 |
| 生成上下文 | 生成任务创建时勾选素材，Agent 通过 `fetch_material` 工具读取融入正文 | `article_assets(usage=context)` |
| 引用卡片 | URL 素材插入生成 citation 卡片，展示标题+域名+摘要 | doc.citations + `usage=referenced` |

**引用完整性规则**：删除被文章引用的素材时返回冲突提示（40900），提供「解除引用」确认操作；解除后文章内块降级为占位符「素材已移除」。

## 4. 权限与合规

- 素材严格归属上传账号，仅本人可见可管理（三期再考虑共享素材库）。
- 上传校验：扩展名 + MIME 双校验、大小限制、图片/视频病毒扫描（ClamAV）。
- 所有权声明：首次上传引导勾选「我已确认对该素材拥有合法权利」。
- 视频转码消耗控制：单用户并发转码任务 ≤ 2。

## 5. 前端交互要点（详见 08 文档）

- 素材中心页：类型 Tab（全部/图片/视频/文档/链接）+ 网格卡片（封面、标题、标签、状态角标）+ 拖拽上传区。
- 上传进度条（XMLHttpRequest 直传进度）；处理中素材展示 skeleton，就绪后自动刷新。
- 编辑器素材面板：搜索框 + 素材网格 + 插入 hover 操作。

## 6. 验收标准

- [ ] 四类素材导入→解析→打标→就绪全链路通过；doc 正文抽取准确率人工抽检 ≥ 95%
- [ ] 预签名直传不走后端带宽；上传中断可重试
- [ ] 编辑器插入图片/视频后保存，重新打开文章渲染一致（块级 doc 往返无损）
- [ ] 删除被引用素材返回冲突提示；解除引用后文章占位符正确
- [ ] 超限/非法类型上传被拒并给出明确错误码
- [ ] 生成任务勾选素材后，产出文章中素材内容被实际引用（集成测试断言）
