### 2.4 M1 验收（Demo 场景）

1. 注册登录 → 左栏三栏工作台 → 选择模型发起教育问答，回答带来源引用；
2. 输入「帮我写一篇海淀幼升小攻略」→ 生成任务进度推进 → 草稿自动出现在「我的文章」（作者=当前账号）→ 编辑发布；
3. docker-compose 一键拉起全链路。

## 4. M3 / M4 / M5 待细化项

M3：审核工作台、举报流、政策版本管理（is_current 切换）、专栏/关注/评论、视频转码链路（FFmpeg worker）、**会员积分计费体系（Spec 11：沙箱控制/积分扣费/支付对接）**。M4：推荐系统、政策时间轴问答、学科辅导类 Agent 扩展、移动端适配。M3 启动前基于 M1/M2 实测补充细化 Spec（沿用本文档编号追加 09-x 附录）。

**M5 桌面版 SDK**：拆分与排期已在 `10-桌面版SDK建设.md` 完整定义（含启动 Gate），排在所有 Web 端里程碑之后最后实现；其前置扩展点（OAuth Device Flow/PKCE、前端 platform 抽象层）需在 M3 前预留，避免后期改造。

## 5. 风险与人力建议

- 最小可行团队：后端 ×2（1 人偏 AI 编排）、前端 ×1.5、兼职测试/项目管理 ×0.5。
- 关键路径：T2.6→T2.7（LangGraph 流水线）与 T3.3（对话工作台），优先保障；Prompt 评测冒烟集与安全拦截样例集在 T2.7 启动前准备完毕。
- 外部依赖：大模型 API 额度与文生图版权需在 M1 前落实。
