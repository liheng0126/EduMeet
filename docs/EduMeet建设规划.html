01项目定位与核心诉求

EduMeet 是一个面向全国中小学生教育场景的网页版 AI 智能体平台，围绕「入学政策 / 学习资料 / 家庭教育思路 / 学生学习经验 / 教师教育经验」五大主题，为家长、学生、教师提供信息聚合 + AI 生成 + 经验分享的一站式服务。

1.1 核心诉求

🎯

消除信息偏差

家长面对各地入学政策、升学路径、教育资讯存在严重的信息不对称，Agent 聚合开源权威内容并支持语义检索，帮助家长快速获得准确、可比对的信息。

🤝

经验分享平台

沉淀家长、学生、教师三方的一手经验：AI 辅助生成结构化文章，图文并茂发布，形成可检索、可查阅的教育经验内容库。

🧠

AI 多智能体协作

基于 LangGraph 编排的写作 / 审核 / 配图 / 政策核查等多智能体流水线，自动生成图文文章并与账号自动绑定归属。

1.2 平台内容来源（双轨制）

内容来源说明使用方式
开源网络文章教育部及各地教育局官网、权威教育媒体、公开教育社区的开源内容采集/导入 → 治理脱敏 → 建立公开内容库，供检索查阅与 RAG 引用；标注来源与版权属性
平台私有文章用户（家长/学生/教师）创作、AI 辅助生成、自定义导入的素材文章与账号绑定归属，按权限（私有/可见/公开）管理，支持图文、嵌入素材
合规前置声明：平台内容涉及未成年人教育与政策信息，建设全程需遵守内容安全审核、个人信息保护（不上传未成年人身份信息）、开源内容版权标注三项红线，详见 第 8 章。

03产品功能蓝图

💬

F1 对话式问答

对标 ChatGPT 的对话主界面；基于 RAG 检索政策与经验库回答教育问题，支持多轮会话、会话历史管理。

📝

F2 文章自动生成

多智能体流水线生成图文文章（标题/大纲/正文/配图），生成结果自动绑定当前账号，可编辑后发布。

🔍

F3 文章检索与图文阅读

全文 + 语义混合检索；图文界面化阅读器（目录、图片灯箱、视频播放），支持分类/标签/专题浏览。

🗂️

F4 素材中心

自定义导入文章素材、图片、视频；素材自动解析、打标，可一键插入文档/文章生成流程。

🤖

F5 自定义大模型

用户在设置中自选大模型（官方预置 + 自定义 API Key 接入），生成/对话按所选模型路由。

👤

F6 个人中心

我的文章、我的素材、我的会话、账号角色与隐私设置、会员与积分（见第 11 章）。

📚

F7 公共内容库

开源网络文章的聚合治理库：政策库（按省市分级）、学习资料库、经验精选，全部可检索可溯源。

🛡️

F8 管理后台

内容审核工作台、举报处理、内容源配置、模型与配额管理、数据看板。

🔔

F9 消息通知中心

站内信统一收口：生成完成、审核结果、互动通知、系统公告；支持邮件/短信渠道分发（见 13.2）。

🧭

F10 引导与帮助

新手三步引导、场景化模板入口、帮助中心与反馈工单，降低家长用户上手门槛（见 13.6）。

4.1 关键架构决策

决策点选型理由
多模型接入LiteLLM 统一网关OpenAI 兼容协议屏蔽各厂商差异；支持用户自带 API Key、按模型计费统计与配额控制，天然满足「自定义选择大模型」需求
AI 编排LangGraph（Supervisor 模式）文章生成是多步有状态流水线（规划→写作→配图→核查），图结构编排支持断点重试与人工介入审核
检索ES 全文 + 向量语义混合检索（RRF 融合）政策类查询需关键词精确匹配（如「2026 北京幼升小」），经验类查询需语义泛化，二者融合效果最佳
生成任务异步化Celery + Redis图文文章生成耗时长（30s~3min），必须异步 + 进度推送（SSE），避免阻塞请求
文件存储对象存储 + 预签名直传图片/视频大文件不走应用服务器，前端直传 OSS 提升上传体验

6.1 文章自动生成流水线（多智能体）

→

政策事实核验 + 内容安全
→
草稿落库
自动绑定当前账号
→
用户编辑 → 发布
  • 账号自动绑定：生成任务创建时即写入 author_id = 当前登录账号，草稿与成品全生命周期归属该账号，预留多人协作扩展字段。
  • 图文模式：写作 Agent 按节输出「文本 + 配图指令」，配图 Agent 两条路：① 从用户素材库/公共图库选图（优先，版权安全）；② 调用文生图模型生成插画。图文以结构化 JSON（块级文档模型）存储，编辑器与阅读器共用。
  • 素材融入：生成前用户可勾选素材，Agent 通过工具调用读取素材内容/图片元信息并自然融入正文相应章节。
  • 进度可视化：前端实时展示当前 Agent 阶段（大纲→写作→配图→核查），支持中途取消与重新生成单节。

  • 结果展示：卡片式列表（标题、摘要、封面图、来源标签「官方政策/社区经验/私有文章」、更新时间）；支持省市/学段/主题/角色多维筛选。
  • 阅读器：块级文档渲染，支持目录导航、图片缩放、视频播放、AI 摘要、相关文章推荐。

6.3 素材中心与文档集成

  • 导入通道：拖拽上传（图片/视频/Word/PDF/TXT/Markdown/URL 链接）、剪贴板粘贴、URL 抓取解析。
  • 自动加工：文档抽取正文 → 图片/视频生成元信息 → 素材理解 Agent 自动打标（主题/学段/摘要）→ 入素材库。
  • 集成方式：① 编辑器内素材侧栏拖拽插入；② @ 唤起素材选择器；③ 生成文章时勾选素材作为上下文；④ URL 素材自动生成引用卡片。
  • 视频处理：上传后异步转码、截取封面帧，文章中以内嵌播放器展示。

6.4 自定义大模型

  • 官方预置模型：平台统一配置若干主流模型（不锁定单一厂商，选型推荐与分批接入计划见 7.2 模型推荐矩阵），用户下拉选择。
  • 自定义接入：用户可填写 OpenAI 兼容 API（Base URL + Key + 模型名），密钥加密存储，仅本人会话/生成生效。
  • 路由实现：LiteLLM 按请求携带的模型标识路由，统一处理超时、重试、降级、用量统计与配额。
  • 沙箱控制与计费：登录账号分级沙箱——免费用户仅可用免费模型与每日额度，付费会员按等级开放不同模型；消耗按积分扣款，积分与百万 token 定价等比兑换并预留 5% 利润空间，详见 第 11 章。

6.5 公共内容库治理（开源文章来源）

  • 采集范围白名单：教育部/各地教育局官网、权威教育媒体 RSS、开源教育内容站。
  • 入库流程：抓取 → 正文抽取 → 去重 → 来源与版权标注 → 政策条目结构化（省市/学段/年份）→ 审核 → 建索引。
  • 政策时效管理：按年度/地区维护版本，过期政策降权并标注「历史版本」。

11会员体系与积分计费（沙箱控制）

大模型调用按 token 向厂商付费，平台通过「会员分级 + 积分扣款」回收成本并盈利：充值金额等比兑换积分，模型消耗按积分单价扣款，单价与厂商百万 token 定价等比例换算，中间预留 5% 利润空间；免费用户受沙箱控制只能使用免费模型。积分模式参考 Cursor / Manus / Genspark / 扣子等主流 Agent 产品惯例。详细规则与数据设计见 Spec 11-账号会员与积分计费体系.md。

11.1 积分换算规则

# 核心公式（单价随厂商调价在管理后台维护，积分自动重算）
充值汇率：1 元 = 10 积分
模型混合单价(元/百万token) = (输入价×3 + 输出价×1) ÷ 4   # 输入:输出 = 3:1 加权
模型积分单价 = ceil( 混合单价 × 10 × 1.05 )               # 1.05 = 5% 利润空间
生图积分单价 = ceil( 单张成本 × 10 × 1.05 )

13平台运营、合规与体验支撑体系

除核心 Agent 能力外，平台的规模化运营与合法上线还依赖六类支撑体系：账号登录方式补全、消息通知中心、合规资质与青少年模式、数据埋点与运营体系、容灾备份与灰度发布、新手引导与帮助中心。均已同步至对应 Spec 文档索引，实现排期归入第 9 章对应里程碑。

13.1 登录方式补全（详见 Spec 02/08）

  • 手机验证码登录：教育场景家长/教师均以手机号为主账号，一期即支持；短信通道接入阿里云/腾讯云 SMS，频控与图形验证码防刷。
  • 微信扫码 / 公众号登录：覆盖家长侧最高频入口；UnionID 打通 Web 与后续桌面端、小程序端同一身份。
  • 游客模式：未登录可浏览公开内容与检索，触发生成/收藏/会员操作时引导注册，降低首访流失。

13.2 消息通知中心（详见 Spec 03 §通知接口）

新增 notification-service（L2 应用服务层）：站内信 + WebSocket 实时推送 + 邮件可选，消息已读/未读、聚合去重，头像铃捕红点入口。

通知类型触发时机通道
任务结果文章生成完成/失败、素材导入完成站内信 + WebSocket
审核结果文章/素材审核通过、驳回及驳回理由站内信 + WebSocket
互动通知评论/回复/收藏/点赞站内信（聚合）
会员与余额积分不足预警、赠送积分到期提醒、充值到账站内信 + WebSocket
系统公告模型上下线、维护窗口、新功能发布站内信 + 邮件

13.3 合规资质与青少年模式（详见 Spec 09 里程碑前置任务）

  • 备案清单：ICP 备案（上线前置）、算法备案、生成式 AI 服务备案（大模型上线登记），域名/服务器主体一致性提前规划。
  • AI 内容标识：按《人工智能生成合成内容标识办法》在生成文章页与导出文件中标注「AI 生成」。
  • 青少年模式：未成年人身份申报后启用：内容过滤加强、使用时长提醒、默认关闭付费能力。

13.4 数据埋点与运营体系（详见 Spec 08 运营看板）

  • 埋点模型：统一事件模型（user_id / event / properties / timestamp），核心漏斗：注册→首次生成→首次收藏→付费转化。
  • 运营位：首页轮播 + 侧边运营卡片，支持配置化投放（活动/新模型/公告）。
  • 内容冷启动：官方预置分省市政策库与精选经验文章种子池，配合创作者激励（积分奖励）解决冷启动。

13.5 容灾备份与灰度发布（详见 Spec 01/09）

  • 备份策略：PostgreSQL 每日全量 + WAL 归档，RPO ≤ 1h；对象存储跨区冗余；每季度恢复演练。
  • 发布策略：按用户尾号灰度（1%→10%→50%→全量），Prompt 变更走 A/B 并关联评测体系（评测/ 目录 D8 线上监控域）。

13.6 新手引导与帮助中心

  • 新手引导：首访 3 步引导浮层（提问→生成文章→查资料）；示例 Prompt 一键填入。
  • 帮助中心：FAQ（入学政策适用范围、积分计费说明、内容免责声明）+ 意见反馈入口，反馈直达运营看板。
同步要求：本章内容需在下一轮同步进 Spec 02（通知/埋点表结构）、Spec 03（通知接口）、Spec 08（引导/帮助/运营位页面）后进入排期。
