# E2 - 智能体链路质量评测（文章生成 / RAG 问答 / Agent 行为）

> 版本：v1.0 ｜ 状态：待评审 ｜ 上游：E0/E1 ｜ 被测对象：docs/spec/04 文章生成与智能体编排

---

## 1. 目标与范围

对 EduMeet 核心 AI 链路建立可重复的质量评测：D1 文章生成质量、D2 RAG 问答质量、D5 Agent 行为可靠性。评测以真实链路调用为准（评测环境 Docker 起完整服务，非 Mock）。

## 2. D1 文章生成质量评测

### 2.1 执行方式

- 输入：DS2（冒烟 10 / 全量 100）逐条调用 `POST /generation-tasks`，等待任务完成取回草稿。
- 运行配置：固定 model_ref、固定 prompt 版本（记录 run 元数据）；并发 3，单条超时 10 分钟。

### 2.2 指标与判定

| 指标 | 层 | 判定方式 | 门禁 |
|---|---|---|---|
| 任务完成率 | L1 | 流水线 done 且产出非空 | ≥ 90%（全量）/ 100%（冒烟） |
| 结构完整率 | L1 | 块级 doc 含 heading/paragraph/image，章节 ≥ 大纲数 80% | ≥ 95% |
| 要点覆盖率 | L3 | Judge 对比 gold_outline/key_points 逐条判定 | ≥ 80% |
| 政策事实准确率 | L3 | 对 DS1 衍生生成题，核对数字/时间/条件是否与金标一致 | ≥ 98%（零容忍级） |
| 图文相关性 | L3 | Judge 按节评分 1~5（图与节语义匹配） | 均分 ≥ 4.0 |
| 引用规范率 | L1 | 政策类文章 citations 非空且链接可访问 | 100% |

### 2.3 Judge Rubric（要点覆盖示例）

```
你是教育内容评审员。对照【金标要点】逐条检查【文章正文】：
- 2 分：要点被准确转述且无事实错误
- 1 分：要点被提及但表述模糊/部分错误
- 0 分：要点缺失或与金标冲突
输出 JSON：{"per_point":[{point, score, evidence}], "coverage_rate": x}
```

## 3. D2 RAG 问答质量评测

### 3.1 执行方式

- 输入：DS1 全量 200 题 → `POST /sessions/{id}/messages`（use_rag=true），收集完整回答 + citations + Langfuse trace（检索上下文）。
- RAGAS 指标需要检索上下文：从 trace 提取检索片段与回答配对计算。

### 3.2 指标与判定

| 指标 | 计算方式 | 门禁 |
|---|---|---|
| 忠实度 faithfulness | RAGAS：回答可归因于检索内容的比例 | ≥ 0.90 |
| 答案相关性 answer_relevancy | RAGAS | ≥ 0.85 |
| 上下文精度 context_precision | RAGAS（检索排序质量反哺 D3） | ≥ 0.80 |
| 政策事实准确率 | Judge 对 key_points 判定（同 D1 口径） | ≥ 98% |
| 引用准确率 | 规则：链接可访问 + Judge 判定内容相关 | ≥ 95% |
| 时效标注率 | L1：回答含时效提示/版本标注 | 100% |
| 时效陷阱题正确率 | DS1 trap_type≠none 子集：识别旧版本并提示 | ≥ 90% |

## 4. D5 Agent 行为可靠性评测

| 指标 | 方法 | 门禁 |
|---|---|---|
| 任务完成率 | DS2 全量端到端 | ≥ 90% |
| 工具调用正确率 | 解析 LangGraph 轨迹：调用的工具名与参数符合该阶段预期（如 planner 应调用 search_library） | ≥ 95% |
| 断点恢复成功率 | 注入故障（LLM 超时/节点异常）后从失败阶段续跑成功 | ≥ 95% |
| 阶段时长分布 | 各 Agent 节点耗时 P50/P95 | 无门禁，性能基线记录 |
| 回炉收敛性 | reviewing→planning 回炉 ≤ 2 次收敛 | 100%（>2 次即 failed） |

## 5. 失败归因与报告

- 每个失败样例自动归档：输入、产出、Judge 评分明细、Langfuse trace 链接、初判原因（检索失败/生成幻觉/安全误拦/超时）。
- 报告按域给出得分 + Top 失败模式聚类（LLM 归纳），辅助 Prompt/链路优化排期。

## 6. 验收标准

- [ ] M1：冒烟套件（DS2×10）跑通并接入 CI，完成率 100% 门禁生效
- [ ] M2：全量套件上线，四层评测全部实现，报告含失败归因
- [ ] 指标可复现：同 run 环境重跑两次，L1/L2 指标完全一致，L3 一致率 ≥ 95%
- [ ] 政策事实准确率、时效标注率按零容忍口径执行（不达标阻断发布）
- [ ] 时效陷阱题与素材融入专项用例有独立得分
